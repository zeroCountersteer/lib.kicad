# KiCad project templates

This directory contains reusable KiCad project starters. The
`General-Project` template uses the well-organized `wired` SBC project as a
reference for page setup, BOM fields, and project settings, but contains no
SBC-specific circuitry.

Templates are source design material, not verified reference designs. Every
new project must be electrically, mechanically, thermally, and manufacturably
reviewed before release.
